DemonCAT

Demon Computing Availability Tools

专注于计算故障注入工具。覆盖 CPU / 存储 / 网络 / 进程 / NPU 五大模块, 提供统一命令面、预检护栏、状态跟踪。
加一个故障 = 加一个脚本 + 配置文件一行,免重新编译。

33 故障 5 模块 远程控制台 C11 + CMake
远程控制台 → 浏览故障目录

核心特性

从故障注入到远程控制,一个工具覆盖计算可用性测试全链路。

⚙

5 模块覆盖

CPU / 存储 / 网络 / 进程 / NPU,共 33 条故障,横跨系统栈各层。

🔌

插件化故障

外部脚本 + 声明式配置接入。加一个故障 = 加一个脚本 + 配置一行,免重新编译。

🛡

预检护栏

注入前参数校验、操作合法性检查、同资源重注入拒绝,避免误操作。

📊

状态跟踪

state.json 持久化、query 幂等、clean --all 批量清理,断电不丢状态。

🌐

远程控制台

dcat serve 长驻 HTTP,经 SSH 隧道远程查看/注入/清理;默认只读,--allow-write 开写。

⚡

极简依赖

纯 C11 + CMake,cJSON 单文件库,最小 Linux 环境 + bash 即可运行。
